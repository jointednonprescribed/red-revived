
# red-revived

A Minecraft mod for 1.21.1-1.21.11 which attempts to revive old ideas from the RedPower (AKA ProjectRed in later versions) and integrate them with some new ones. Utilizes a core framework for passive compatibility called 'Bundled': <a href="https://github.com/jointednonprescribed/bundled" target="_blank">https://github.com/jointednonprescribed/bundled</a>
